# 证据账本

对每项发现使用一行或一个小节记录：

| 字段 | 内容 |
|---|---|
| 编号 | 稳定编号，如 F-01 |
| 调查主张 | 可证伪的一句话 |
| 目标位置 | 论文、页码、图表或段落 |
| 来源位置 | 来源论文、页码、DOI或官方链接 |
| 观察事实 | 不带推断的直接描述 |
| 匹配类型 | 字节级、感知相似、局部复用、文本重合、数值重合、逻辑矛盾、网络关系 |
| 复核方法 | 哈希、渲染比较、全文检索、手工核对、官方记录 |
| 替代解释 | 合法复用、公共数据、模板、巧合、排版错误等 |
| 证据等级 | A、B、C或D |
| 状态 | 已确认、强指示、待核、已排除 |
| 证据文件 | PDF、截图、JSON、表格或网页存档 |

## 数值与表格比较附加字段

- 模型/表号、列号、变量名及完整数值串（系数、标准误、显著性）；
- 观测数、样本/国家数、对数似然、伪 R²、Wald/LR/F 检验和 AIC/BIC；
- 目标与来源的差异类型：原样、四舍五入、替换标签、局部改数、增删列或重新排版；
- 目标声称的样本、年份、地区与表内实际范围；
- 数据集的准确官方名称、提供者、下载日期、覆盖范围和可复现链接；
- 一次精确检索使用的数值/短语，以及命中的来源与访问日期。

数值相同只在模型、定义、量纲和样本语境也能对应时提升为强证据；公共基准数据或作者明确披露的复算不得误报为不当复用。

## 图像比较最小记录

- 两个文件的完整路径和PDF版本；
- 页码、图号和裁剪范围；
- 原始文件SHA-256是否相同；
- 感知哈希算法、位数和距离；
- 是否存在缩放、旋转、翻转、改色、重排或截图；
- 人工核对看到的独特对应点；
- 工具局限和误报可能。

## 网络边记录

每条作者网络关系应写明：

- 节点A与节点B的准确身份；
- 关系类型及对应DOI；
- 首次与最近一次出现日期；
- 是否为直接共同署名；
- 是否存在官方诚信记录；
- 该记录针对文章、流程还是个人；
- 身份消歧置信度。
